**T2D Digital Twin**

## 4. Problem Statement & Healthcare Use Case

Type 2 Diabetes requires continuous management, yet glucose excursions are often recognised only after they occur. This proof of concept builds a **Digital Twin of a T2D patient** that combines historical EHR-style information with glucose and wearable signals to **predict a hyperglycemic event (glucose > 180 mg/dL) within the next 2 hours**.

The system demonstrates how multiple data streams can be fused to estimate future risk and present that risk through a clinician-oriented dashboard.

- **Static stream (EHR, synthetic):** age, BMI, HbA1c, diabetes duration, family history, metformin use
- **Dynamic stream (synthetic CGM/glucose):** current glucose, 15/30/60-minute changes, 1-hour rolling mean and maximum
- **Wearable stream (simulated):** heart rate, HRV, steps, prior-night sleep, hour of day
- **Output:** 2-hour-ahead hyperglycemia risk score + clinician dashboard (`dashboard.html`)

## 6. AI/ML Model Details

- **Model:** HistGradientBoostingClassifier (scikit-learn)
- **Features:** EHR (6) + CGM/glucose features (6) + wearable features (5)
- **Total fused features:** 17
- **Label:** glucose above 180 mg/dL at any point in the next 120 minutes
- **Split:** patient-level split; 300 synthetic patients over 14 days, with 25% of patients held out for testing
- **Prediction:** model probability of a hyperglycemic event within the next 2 hours

### Results

| Input streams | ROC-AUC | PR-AUC | Recall | Precision |
|---|---:|---:|---:|---:|
| Glucose only | 0.960 | 0.938 | 76.1% | 96.3% |
| Glucose + wearable | 0.993 | 0.986 | 93.2% | 93.5% |
| **EHR + CGM + wearable (fused)** | **0.996** | **0.990** | **94.6%** | **94.5%** |

> **Important limitation:** All data is synthetic and generated by the project's simulator (`twin_poc.py`). These results demonstrate the proof-of-concept pipeline on synthetic test data and do not represent clinical or real-world performance.

## 7. Data

Only synthetic data is used. All patient records and signals are generated inside `twin_poc.py`.

No real patient data is included in this repository.

## 8. Run

Install the required dependencies:

```bash
pip install numpy pandas scikit-learn
```

Train and evaluate the model (writes `results.json` and `demo_patient.json`):

```bash
python twin_poc.py
```

Open `dashboard.html` in any web browser to view the clinician dashboard (no server needed).
